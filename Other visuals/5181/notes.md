Before you can do this exercise, you'll need to download and unzip this file .
Open the Class Days - Gauge.pbix file from the folder shown above.

Add a Slicer containing Day of Week and set to Single select.

Power BI Slicer selection properties
You'll find this in the Slicer settings section.

Add a Gauge visual and set the Value to show Average of Attendees with a Maximum value of Max of Attendees.

Power BI Gauge buckets
You don't need to set the Minimum value.

Set the gauge's Target to 11 in the Gauge axis properties.

Change the Title of the Gauge to Average daily attendance.

Add a Visual border with rounded corners to the gauge.

Use the slicer to filter the gauge.

Power BI Gauge visual
Monday's value is just above our target.

To make the gauge more interesting consider adding conditional formatting to the Fill color property. Use the diagram below as a guide.

Power BI Rules based Conditional formatting
Make sure to change the Summarization option to Average.

Using the slicer, try changing the day of the week.

Power BI Gauge with Conditional formatting
Unsurprisingly attendance on Fridays is well below target!
