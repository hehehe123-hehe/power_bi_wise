This exercise is provided to allow potential course delegates to choose the correct Wise Owl Microsoft training course, and may not be reproduced in whole or in part in any format without the prior written consent of Wise Owl.

Before you can do this exercise, you'll need to download and unzip this file .
Open a blank Power BI file and import data from the Excel file called Running Data 2023.xlsx from the folder above.

Add a text box titled Running Stats, showing the following data highlights.

Power BI Text box showing Values
Click +Value on the textbox toolbar to add the blue underlined values.

Add a table visual showing the Quarter from the Date column with the Sum of Time in Mins.

Power BI Table visual showing Quarters
You can clearly see the good intentions at the the start of the year!

Add a column chart with Month on the X-axis and Sum of Distance KM on the Y-axis.

Make sure no visuals are selected and add a smart narrative visual.

You may be given a choice between Copilot (preview) and Custom. Choose Custom.

 

Power BI Smart narrative visual
Power BI will attempt to offer insights for the visuals on the page.

Try selecting various data points from the 3 visuals to see the insights change.

Power BI Smart narrative
Here I selected the value 844 for Qtr 2 in the table.
