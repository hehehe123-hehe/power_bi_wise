# [Using a KPI visual with a Slicer](https://www.wiseowl.co.uk/power-bi/exercises/power-bi-desktop/advanced-visuals/5185/)

This exercise is provided to allow potential course delegates to choose the correct Wise Owl Microsoft training course, and may not be reproduced in whole or in part in any format without the prior written consent of Wise Owl.

Before you can do this exercise, you'll need to download and unzip this file .
Open the Class Day - KPI.pbix file from the folder shown above.

Add a KPI visual with Average of Attendees in the Value bucket and Class Date - Month in the Trend axis bucket.

Create a Target table using the Enter data icon on the Home tab of the ribbon.

Power BI Create Table
Name the table Target.

Add the newly created Target to the Target bucket of the KPI. It should now look like this:

Power BI KPI
Switch on the Date in the Visual formatting section.

Add a slicer with Class Date - Month then switch on the Select all option.

Select all months in the slicer, then try switching off months to find the last month that the target wasn't achieved.

Save the file as Lazy September.pbix
