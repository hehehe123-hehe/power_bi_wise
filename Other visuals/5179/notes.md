# [Using the new Card visual to show various items of key data](https://www.wiseowl.co.uk/power-bi/exercises/power-bi-desktop/advanced-visuals/5179/)

This exercise is provided to allow potential course delegates to choose the correct Wise Owl Microsoft training course, and may not be reproduced in whole or in part in any format without the prior written consent of Wise Owl.

Before you can do this exercise, you'll need to download and unzip this file .
Open the Tall Buildings.pbix file from the folder shown above.

Add the Card(new) visual, an image of which you can see below.

Power BI Card(new) visual
Its the Card icon with a lightning bolt!

Set the Card to contain the columns as shown below.

Power BI bucket
You could rename the Labels should you choose to.

In the Visual formatting section set the Layout to Grid, Max rows shown to 2 and Columns shown to 3.

In the Callout values, Label section apply a Bold font and set Position to Below Value.

In the Cards section set the Shape to Rounded Rectangle and change the Border Color setting as desired, with a Width of 3px. In the same section add a Background Image using Tall Buildings.jpg from above folder and set the Transparency to around 60%.

Power BI Card(new) visual
Much easier than adding 6 individual card visuals.

If you want a bit of a challenge, set the Sum of Height m and Sum of Floors above ground to not round up to thousands.

To stop values being rounded in some Power BI visuals you can set the Display units to None.

Add a Stacked column chart with Country on the X axis and Count of Building Name on the Y axis. Click various columns to see how they interact with the Card values.

Save the file as Play your cards right.pbix
