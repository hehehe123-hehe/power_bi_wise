# Power BI Practice — Wise Owl Exercises

Personal practice log for working through the 160 free Power BI Desktop exercises published by [Wise Owl Training](https://www.wiseowl.co.uk/power-bi/exercises/power-bi-desktop/), spanning 36 topics from basic reports to calculated columns, advanced tables, and advanced data sources.

> Exercises and source files belong to Wise Owl Training. This repository only contains my own worked solutions and notes — no original exercise files or instructions are redistributed here.

## Why this repo

Documenting hands-on practice with Power BI Desktop (data import, basic DAX, visuals, filtering, and formatting) relevant to data analyst and reporting roles — a companion to the Excel exercises already tracked separately.

## Structure

Each exercise gets its own folder, named by topic and exercise number:

```
powerbi-wiseowl/
├── basic-reports/
│   └── 4465-abba-songs-table/
│       ├── report.pbix
│       └── notes.md
├── calculated-columns/
│   └── 5171-basic-calculated-columns/
│       ├── report.pbix
│       └── notes.md
└── ...
```

Each `notes.md` briefly covers what the exercise practiced, the approach taken, and any functions or techniques worth remembering.

## Skills covered

- Basic reports: tables, matrices, importing from multiple sources (Excel, CSV, web, SQL Server)
- Query editor: cleaning, transforming, unpivoting, splitting/renaming columns
- Filtering & interactivity: slicers, page/report filters, drill-through, bookmarks
- Visuals: column/line/pie/donut/waterfall/bubble/tree map charts, maps (Azure Maps, ArcGIS)
- Calculated columns & basic DAX: IF, SWITCH, RELATED, DATEDIFF
- Conditional formatting: data bars, icons, field-based dynamic colors
- Built-in analytics: trend lines, average/min/max lines, decomposition tree
- Advanced data sources: parameters, custom functions, combining queries, APIs
