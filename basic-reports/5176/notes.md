### Open the Tours - Charts.pbix file from the folder shown above.
> Add 3 card visuals showing the following.
> * Sum of Actual Gross
> * Average of Actual Gross
> * Max of Actual Gross
> * Make sure the 3 cards are the same size, aligned and distributed evenly.
### Power BI Card visual
> * To distribute evenly use the Align icon on the Format tab of the ribbon.
> * Apply some General formatting to the first card such as Background color, Visual border and Shadow.
> * Under Visual formatting change the Callout Color and set its font to italic, also turn off the Category label.
> * Add a suitable title to each Card.
> * Use the Format painter to copy the formatting to the other 2 cards.

### Power BI formatted Card visual
> The formatted cards.
> * Add a Slicer which shows the Country and change its style to Tile.
> * Add a Stacked Bar chart with Tour name on the Y axis and Sum of Actual gross on the X axis. Switch between different countries to see how the cards are affected.
