### Open the Power BI file Class Days.pbix from the folder shown above. Add a matrix with the following columns.
> Hierarchy Matrix
> * You only want the Month of the Class Date.
> * Add some suitable formatting, place the Month totals at the bottom and expand the months.
> Power BI Monthly Matrix
> * You can use the icons in the visual header to expand the groups.

### To make the days appear in the right order, select the Day of Week column then choose the Sort by column option and choose the Weekday column.
> Power BI Sort by Column
> * The Weekday column numbers the days 1 to 7 with 1 being Monday.
> Use conditional formatting to highlight classes with less than 10 attendees.
> * Power BI Conditional formatting
> * Use a single rule to do this.
### Finally, add a table with Location and Attendees. Click various locations to see the interaction on the Matrix.
> Power BI Interactions
> * Here, Eccles Gym is selected.
