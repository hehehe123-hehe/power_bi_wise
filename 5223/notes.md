Open the file called Movie Data.pbix from the folder shown above.

On Page 1 add a stacked column chart with Certificate on the X-axis and Count of Title on the Y-axis.

Apply conditional formatting to the chart so that its columns use the colour stored in the Back Colour field in the Certificate table.

Power BI chart using field based conditional formatting
Who knew the BBFC had official colours?

Add a calculated column to the Film table using the SWITCH function to create a colour scheme for the film lengths.

DAX SWITCH function
You can use hexadecimal colour codes if you prefer

On Page 2 add a table visual with Title, Sum of Box Office Dollars and Sum of Oscar Wins columns.

Add conditional formatting to the Title column using the calculated column to set the font colour.
