# [Use an API to deal a hand of cards to yourself and show this in Power BI](https://www.wiseowl.co.uk/power-bi/exercises/power-bi-desktop/apis/4605/)

This exercise is provided to allow potential course delegates to choose the correct Wise Owl Microsoft training course, and may not be reproduced in whole or in part in any format without the prior written consent of Wise Owl.

Before you can do this exercise, you'll need to download and unzip this file .
The aim of this exercise is to deal 7 random cards from a new pack:

Dealing cards
As a hint, this is a matrix with the card image being displayed as the column header.

To get the data, get data from the API whose web address is given in the above text file:

Cards API
You can choose to get any number of cards by varying the count argument.

When you've got this working, save your Power BI report as The cards dealt to you and close it down.
