Open the file called Data Bookmark.pbix from the folder shown above.

Add two slicers, one with RegionName and the other with ProductType. The positioning of these slicers is irrelevant because we will eventually hide them.

Power BI Slicers
Using bookmarks we will make viewing this report a little easier for three users.

Three users are responsible for different Regions and Product Types. Instead of having to make selections from the slicers we will use bookmarks so they just have to click a button to see their data.

To see the Bookmarks pane, choose View | Bookmarks from the ribbon.

 Add a bookmark for each of the following selections. Ensure that Data and All visuals are the only items selected for each bookmark.

Power BI Bookmark options
You can change these options using the ... menu for each bookmark.

Create each bookmark as follows naming them User 1, User 2 and User 3.

Open the Selection pane from the View tab in the ribbon and use it to hide the two slicers.

Hiding visuals in the selection pane in Power BI Desktop
Click the visibility symbol to hide an item.

Now we need to add buttons for the users. Insert a blank button and add text to indicate that it's for User 1.

Power BI Button
Apply any other formatting options you like.

Change the button's Action properties so that it shows the User 1 bookmark when clicked.

Power BI Button Action options
You'll have to switch on the Action property to make the changes.

Now repeat the process to create a button for each of the other two users.

Power BI Bookmark Buttons
Hold Ctrl and click each button to see how the visuals are being filtered.
