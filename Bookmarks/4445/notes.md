Create a report where each page is filtered to only include data about one type of dinosaur diet. The files you'll need are in the above folder:

Power BI Filters
How tedious that users have to click the bottom of the page ... !

Using bookmarks create a set of arrows to move back and forth between the report pages.

Power BI Bookmarks Page arrows
Make sure to tick or un-tick Data and Display depending what you want to carry between pages.

Optionally save this as Create a real page turner and then close it down.
