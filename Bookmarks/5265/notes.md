Before you can do this exercise, you'll need to download and unzip this file .
Open the file called Display Bookmark.pbix from the folder shown above.

The aim of the exercise is to create a panel with slicers on, that can be hidden or shown when required.

Use the Insert tab in the ribbon to add a rectangle shape. Resize it and position it on the left of the page.

Power BI Bookmark side panel
Add some text and format the shape.

Add two slicers, one for RegionName and the other for CentreTypeName. Position these within the rectangle and format as desired.

Add a blank button to the slicer panel. Format it as desired and add the text Close Pane.

Power BI Bookmarks Slicer panel
Use the red guidelines to align all the items.

If you have trouble selecting items on the page you may find it easier to use the Selection pane (choose View | Selection from the ribbon to open it).

Group the four items together and name the group Slicer Panel.

Power BI Selection pane
The rectangle shape, two slicers and button grouped.

Add a blank button with the text Show Pane and format it as desired.

An action button in Power BI Desktop
Position this button in the bottom left corner of the page.

Using the Selection pane, hide the slicer panel group. Add a bookmark named Pane in, ensuring only the Display option is selected.

Power BI Bookmark options
Only Display is selected!

Now hide the Show Pane button and unhide the slicer panel group. Add a bookmark called Pane out, ensuring only the Display option is selected.

Select the Close Pane button and set it to display the Pane in bookmark when you click it.

Repeat the process for the Show Pane button but this time show the Pane out bookmark.

When designing reports you must hold the Ctrl key when you click buttons. When the report is published you can just click the button normally.

Try setting various selections in the slicers then opening and closing the pane.

Save the file as Pop in and out.pbix
